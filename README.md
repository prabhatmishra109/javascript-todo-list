# FlowTask — Animated To-Do List

A polished, responsive To-Do List built with plain HTML, CSS, and JavaScript.

## Features
- Add, edit, complete, and delete tasks
- High / medium / low priority
- Optional due dates and overdue labels
- Search and All / To do / Done filters
- Progress bar and task counters
- Clear completed tasks
- Light/dark theme toggle
- Saves tasks in your browser using localStorage
- Responsive layout and CSS animations

## Run in VS Code
1. Extract `FlowTask-ToDo-List.zip`.
2. Open the extracted `animated-todo-list` folder in VS Code.
3. Open `index.html` in a browser, or install the **Live Server** extension.
4. If Live Server is installed, right-click `index.html` → **Open with Live Server**.

No Node.js, npm, or build step is required. An internet connection is only needed for the optional Google Fonts used by the design.
